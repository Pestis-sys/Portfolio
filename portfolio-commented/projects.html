Community Gallery

What
A multi-user photo gallery where members sign up, log in, upload their photos and rate each other’s work.

page_ajax_js.html
function sndReq(by, value) {
  http.open('get', 'display.php?display_by='
    + encodeURIComponent(by)
    + '&display_value=' + encodeURIComponent(value));
  http.onreadystatechange = handleResponse;
  http.send(null);
}

function handleResponse() {
  if (http.readyState == 4) {
    document.getElementById('sideDisplay')
      .innerHTML = http.responseText;
  }
}

AJAX CD catalogue

What
A music catalogue that loads albums by genre or artist without ever reloading the page.
Built with
JavaScript, jQuery, PHP, MySQL
Highlights
Built the same page twice, once with plain JavaScript (XMLHttpRequest) and once with jQuery, to compare the two approaches. The PHP side answers each request from MySQL using prepared statements, which protects against SQL injection.
Takeaway
What actually happens between the browser and the server in an async request.

My Red Bowl Kitchen

What
A niche food site about Manhattan clam chowder, launched and marketed as a class project.
Built with
HTML, CSS, JavaScript, Google Analytics, Search Console, Google Ads, Facebook
